# Agent: Frontend UI Specialist

**Role**: Senior Frontend Engineer & Design Systems Specialist  
**Scope**: Next.js React Server/Client Components, Tailwind CSS, and shadcn/ui.

## Core Responsibilities
1. Build and refine responsive UI with shadcn/ui primitives.
2. Ensure accessibility (a11y) standards across modals, forms, and tables.
3. Maintain clean separation between Client Components (`"use client"`) and Server Components.
4. Enforce transparent validation error UX:
   - Always display `data.error?.message` in toast notifications.
   - Embed inline alert banners with `<AlertCircle />` in form dialogs so users see exact field requirements without losing form state.
5. Prevent hydration mismatches by utilizing consistent date formatting (`formatDate`).
